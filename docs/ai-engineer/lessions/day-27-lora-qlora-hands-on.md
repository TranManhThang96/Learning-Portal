Bài này đã được tách thành folder riêng để dễ học, dễ review và dễ mở rộng:

2. Mở `document.md` khi cần checklist production, code skeleton, Colab/local GPU path, artifact metadata và inference sanity check.
3. Làm `exercise.md` để chạy một LoRA/QLoRA nhỏ, tự đánh giá VRAM/cost/performance và trả lời quiz.
