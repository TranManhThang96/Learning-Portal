# Day 22: Agent Patterns với LangGraph

Bài này đã được tách thành folder riêng để dễ học, dễ chạy lab và dễ mở rộng:

- [Lession: kiến thức chính](day-22-agent-patterns-voi-langgraph/lession.md)
- [Document: production reference](day-22-agent-patterns-voi-langgraph/document.md)
- [Exercise: bài thực hành](day-22-agent-patterns-voi-langgraph/exercise.md)

Gợi ý học trong 2 giờ:

1. Đọc `lession.md` để hiểu agent anatomy, ReAct, router, planner-executor, supervisor và human-in-the-loop.
2. Mở `document.md` khi cần checklist production cho LangGraph: state, checkpoint, interrupt, recursion limit, tool permission, observability và failure modes.
3. Làm `exercise.md` để build support agent có tool calling, router, approval trước side effect, checkpoint/resume và trace.
