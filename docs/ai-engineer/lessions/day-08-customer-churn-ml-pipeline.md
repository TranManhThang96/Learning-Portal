# Day 8: Mini-project - Customer Churn ML Pipeline

Bài học Day 8 đã được tách thành folder riêng để dễ học, dễ tra cứu và dễ thực hành.

## Nội Dung

- [Bài học chính](./day-08-customer-churn-ml-pipeline/lession.md): quy trình xây Customer Churn ML Pipeline theo hướng production-style.

## Mục Tiêu Nhanh

Sau bài này, bạn cần tự build được một pipeline dự đoán churn từ Telco Customer Churn hoặc dataset tương đương: có EDA, feature engineering, ít nhất 3 models, nhiều metrics, error analysis, save artifact, inference function và câu trả lời rõ ràng: dùng được trong production không, nếu có thì cần điều kiện gì.
