# Day 17: LLM Fundamentals

Bài học đã được tách thành folder để dễ học, thực hành và bảo trì.

## Nội dung

- [Lesson](./day-17-llm-fundamentals/lession.md): tokenization, next-token prediction, training pipeline, context window, decoding, model choice và production readiness.
- [Document](./day-17-llm-fundamentals/document.md): checklist, template quyết định model, bảng trade-off, logging và cost worksheet.
- [Exercise](./day-17-llm-fundamentals/exercise.md): bài thực hành đo decoding params, cost, latency, output stability và hosted vs local decision.

## Mục tiêu sau Day 17

Bạn cần giải thích được LLM hoạt động như một probabilistic runtime sinh token kế tiếp, biết tính token budget, biết chọn decoding params theo task, biết trade-off giữa hosted model và local/open-weight model, và trả lời được câu hỏi: dùng LLM trong production được không, nếu có thì cần điều kiện gì.
